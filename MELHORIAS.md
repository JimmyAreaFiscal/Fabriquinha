# Lista de Melhorias com checklist 

O objetivo deste arquivo é documentar as oportunidades de melhorias de funcionalidades e/ou funcionamento do sistema Fabriquinha.


## Potenciais de melhoria

1. O sistema está rodando SonarQube e todos os testes (exceto testes e2e) a cada fim de ticket de implementação. Contudo, o tempo de execução tem se tornado elevado, reduzindo o ganho da Fabriquinha. Idealmente, os testes para tickets de implementação devem ser os unitários dos módulos/pacotes afetados, e o SonarQube deve abordar apenas os arquivos alterados. 

2. Não há informações claras sobre o que está sendo feito em cada ticket. A observabilidade deve melhorar.
